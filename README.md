# CAB 対策ノート（Web-CAB・C-CAB対応）

日本エス・エイチ・エル（日本SHL）の適性検査CABを受ける人のための、無料の対策ガイドです。暗算（四則逆算）・法則性・命令表・暗号の4科目それぞれの解き方の手順、図付きのオリジナル練習問題28問と全問の解説、Web-CAB・紙のCAB・C-CABの違い、結果の扱われ方、7日間と2日間の対策スケジュールをまとめました。SE・プログラマーなどIT職を目指す就活生向けのページもあります。検査に関する事実は日本SHLの公式ページで確認し、公式に公開されていない数字は非公式と明記しています（[出典](docs/sources.md)）。

まず実力を知りたい人は、PrepClubsの[CAB形式の無料模擬テスト](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=srubdn&utm_content=cab)（4科目・全179問）か、このリポジトリの短い[15分診断テスト](docs/diagnostic.md)から始めてください。

## ここから始める

1. **苦手な科目を見つける。** [15分診断テスト](docs/diagnostic.md)を解きます。各科目2問ずつ、全8問で、どこから対策すべきかがわかります。
2. **一番弱い科目から直す。** 下の表からその科目のページを開き、解き方の手順を読んでから、練習問題5問を解きます。
3. **計画に沿って進める。** [7日間プラン](docs/study-plans.md#7日間プラン)、締切が近いなら[2日間プラン](docs/study-plans.md#2日間プラン)を使います。

## 基本情報

| | |
|---|---|
| 提供元 | 日本エス・エイチ・エル株式会社 |
| 対象 | ITエンジニアやデジタル人材のポテンシャル測定（新卒・中途、未経験者も可） |
| 科目 | 四則逆算（紙のCABでは暗算）、法則性、命令表、暗号、パーソナリティ（OPQ） |
| 所要時間合計 | 72〜95分 |
| 実施形態 | 紙、Web（Web-CAB）、テストセンター（C-CAB） |
| ノルム | 大卒 |
| 予測する職務適性 | SE、プログラマー、カスタマーエンジニア、プロジェクトマネージャー |
| 科目ごとの問題数・時間 | 公式サイトでは非公開（非公式の参考値は[こちら](docs/formats.md)） |
| 合格ライン | 公開されていない。企業ごとに判断 |

出典：[日本エス・エイチ・エル CABの製品ページ](https://www.shl.co.jp/service/assessment/cab/)（2026年11月25日確認）

## 4科目の概要

| 科目 | 何をするか | 公式の説明が挙げる力 | ガイド |
|---|---|---|---|
| 暗算（四則逆算） | 式の答えや□に入る数を選ぶ | おおよその答えを速く正確に求める力 | [暗算（四則逆算）](docs/sections/anzan.md) |
| 法則性 | 並んだ図形の規則を見抜き、空欄の図形を選ぶ | プログラマーとしての優秀性 | [法則性](docs/sections/housokusei.md) |
| 命令表 | 記号の命令を順番どおり実行し、結果を選ぶ | コンピュータ言語への適応 | [命令表](docs/sections/meireihyou.md) |
| 暗号 | 例から記号の意味を推理し、変化後の図形を選ぶ | システム設計やデバッグの適性 | [暗号](docs/sections/angou.md) |

どの科目のページも同じ構成です：何を測る科目か、問題の形、解き方の手順、落としやすいポイント、時間の目安、オリジナル練習問題5問と解説、採点表。図形の3科目の問題は、すべて図で出題しています。

## このリポジトリの使い方

- **GitHub上でそのまま読めます。** どのページにも「前へ」「次へ」「目次へ」のリンクがあるので、本のように順番に読めます。
- **答えを見る前に選ぶ。** 答えは「答えと解説」を開くと表示されます。先に自分の答えを決めてから開いてください。
- **正解した問題の解説も読む。** 解説には、近い選択肢がなぜ違うのかも書いてあります。そこに一番の学びがあります。
- **ミスを記録する。** 間違えた問題は、ミスの種類ごとにメモします。やり方は[対策スケジュール](docs/study-plans.md#ミスの記録のしかた)にあります。
- **時間を計って練習する。** このノートは解き方を教えます。ペースは、[PrepClubsの無料模擬テスト](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=srubdn&utm_content=cab)のような時間制限つきの通し練習で身につけます。
- **クローンやフォークも自由です。** 自分用のメモを書き込みたいときにどうぞ。GitBookの形式にも対応しています（[SUMMARY.md](SUMMARY.md)）。

## 練習問題について

28問の練習問題（各科目ページに5問ずつで20問、15分診断テストに8問）は、すべてこのガイドのために作ったオリジナル問題です。CABの本番問題、日本SHLの資料、他の対策本やサイトの問題は使っていません。法則性・命令表・暗号の図形はプログラムで生成し、正解も同じデータから計算して確かめています。命令表と暗号の記号や命令はこのガイド独自のもので、本番とは異なります。

## 誤りの報告

事実の誤り、情報の変更、答えが違うと思う問題に気づいたら、[Issue](https://github.com/mkhalid1/cab-study-notes/issues)かプルリクエストで知らせてください。事実の修正には、日本SHLまたは企業の公式ページへのリンクを添えてください。
