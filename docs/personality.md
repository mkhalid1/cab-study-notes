# 性格検査（OPQ）

**ひとことで言うと：** 仕事での行動の傾向を答える検査です。正解はなく、能力科目のような対策は要りません。大事なのは、形式を知っておくことと、一貫して正直に答えることです。

## 公式に公開されている内容

日本SHLの[CABの製品ページ](https://www.shl.co.jp/service/assessment/cab/)には、CABのパーソナリティ検査について次のように書かれています（2026年11月25日確認）。

- 4つの行動に関する記述の中から、自分に**最も近いもの**を1つ、**最も遠いもの**を1つ選ぶ形式。
- 結果から職務上の行動特性を予測する。
- 知的能力と合わせて、SE・プログラマー・カスタマーエンジニア・プロジェクトマネージャーそれぞれの職務適性と、「ヴァイタリティ」「チームワーク」などの9つのコンピテンシーを予測し、面接でのチェックポイントを示す。

日本SHLは、このパーソナリティ検査を同社の性格検査OPQとして紹介しています。玉手箱Ⅲ、GAB、CAB、RABに共通して付いている科目です。

## 回答の形式

4つの記述が1組になっていて、その中から「最も近い」ものと「最も遠い」ものを1つずつ選びます。このガイドで作った例（本物の質問ではありません）を見てみましょう。

| 記述 | 最も近い | 最も遠い |
|---|---|---|
| 新しい技術はまず自分で触ってみる | | |
| 計画を立ててから作業に取りかかる | | |
| チームの意見をまとめる役に回ることが多い | | |
| 初対面の人とでもすぐに打ち解ける | | |

4つとも好ましく見える記述が並ぶので、「全部当てはまる」と感じることがよくあります。それでも、どれか1つを選ばなければなりません。比べて選ぶ形式なので、全部に「はい」と答えるような回答はできない作りになっています。

## 答えるときの心がけ

1. **仕事や学業の場面を思い浮かべる。** 家族や友人といるときではなく、研究室、アルバイト、チーム開発などの場面での自分を基準にします。
2. **理想の自分ではなく、普段の自分で答える。** 「こうありたい」ではなく「実際にこうしている」で選びます。
3. **深く考えすぎない。** 1組に長く時間をかけると、答えがぶれます。最初に浮かんだ感覚を大事にします。
4. **企業に合わせて演じない。** どんな人物像を求めているかは企業ごとに違い、外からはわかりません。演じた回答は、面接で話す内容とのずれにもつながります。

## 面接とのつながり

日本SHLは、結果を「受検者に対する仮説」として面接で確かめる使い方を紹介しています。低い項目は「業務に支障がないか」、高い項目は「評価に値するレベルか」を面接で確認する、という考え方です。

つまり、性格検査の結果は面接の質問のきっかけになることがあります。「チームで意見が割れたとき、どうしましたか」のような質問に、具体的なエピソードで答えられるよう準備しておくと安心です。IT・SE志望の人向けの準備は[IT・SE志望の就活生へ](it-se-students.md)にまとめました。

## 時間について

科目ごとの問題数や制限時間は、日本SHLの公式サイトには載っていません。非公式の数字は[Web-CAB・紙のCAB・C-CABの違い](formats.md)を見てください。能力科目と続けて受けると後半に疲れが出やすいので、集中できる時間帯を選んで受検しましょう。
