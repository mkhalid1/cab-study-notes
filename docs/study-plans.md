# 対策スケジュール：7日間と2日間

受検案内が届いた時期に合わせて、どちらかのプランを選んでください。どちらも、まず[15分診断テスト](diagnostic.md)で苦手な科目を見つけるところから始めます。

## 7日間プラン

1日あたり45〜60分の想定です。

| 日 | やること | 目安 |
|---|---|---|
| 1日目 | [CABとは](test-overview.md)と[Web-CAB・紙のCAB・C-CABの違い](formats.md)を読み、[15分診断テスト](diagnostic.md)を解く。科目ごとの正解数を記録する | 45分 |
| 2日目 | 診断で最も弱かった科目のページを読み、練習問題5問を解く。間違えた問題は解説を読んで、ミスの種類をメモする | 60分 |
| 3日目 | 2番目に弱かった科目のページで同じことをする | 60分 |
| 4日目 | 残りの2科目のページで同じことをする | 60分 |
| 5日目 | [時間配分](timing.md)を読み、4科目の練習問題を時間を計って解き直す。目標の秒数に収まらなかった問題を書き出す | 45分 |
| 6日目 | 時間を計って模擬テストを通しで解く。[CAB形式の無料模擬テスト（PrepClubs）](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cab)なら4科目を本番に近い形で解ける | 60分 |
| 7日目 | 6日目に間違えた問題を、科目ページの「落としやすいポイント」と照らし合わせて復習する。[受検当日のチェックリスト](test-day-checklist.md)を確認する | 45分 |

## 2日間プラン

受検の締切が迫っているときのプランです。全部をやろうとせず、伸びやすいところに時間を集中させます。

| 日 | やること | 目安 |
|---|---|---|
| 1日目 | [15分診断テスト](diagnostic.md)を解く。そのあと[命令表](sections/meireihyou.md)と[暗号](sections/angou.md)の「解き方の手順」を読み、練習問題を解く。この2科目は初見での戸惑いが最も大きいため、形式を知るだけで点数が変わりやすい | 90分 |
| 2日目 | [暗算（四則逆算）](sections/anzan.md)の「覚えておくと速くなる計算」と、[法則性](sections/housokusei.md)の「解き方の手順」を読む。そのあと時間を計って模擬テストを通しで解き、[受検当日のチェックリスト](test-day-checklist.md)を確認する | 90分 |

## ミスの記録のしかた

間違えた問題は、次の3つに分けてメモしてください。

| ミスの種類 | 例 | 対策 |
|---|---|---|
| 規則・命令の読み違い | 時計回りと反時計回りを取り違えた | 該当科目の「落としやすいポイント」を読み直す |
| 手順の飛ばし | 白黒反転を最後に忘れた | 「解き方の手順」を1つずつ声に出して確認する |
| 時間切れ | 1問に40秒かけて焦った | [時間配分](timing.md)の判断ルールを使う |

同じ種類のミスが3回出たら、それが自分の弱点です。そこを重点的に練習します。

## やらないほうがいいこと

- **問題の丸暗記。** 本番の問題は練習と同じではありません。覚えるべきは答えではなく、解き方の手順です。
- **性格検査の対策に時間をかける。** 性格検査に正解はありません。形式を[性格検査（OPQ）](personality.md)で確認すれば十分です。
- **前日の詰め込み。** 前日は新しいことをせず、各科目の手順を見直す程度にして、よく眠りましょう。
