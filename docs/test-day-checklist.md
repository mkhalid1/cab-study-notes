# 受検当日のチェックリスト

受検形式（Web-CAB、紙のCAB、C-CAB）によって準備は少しずつ違います。細かいルールは企業や形式ごとに異なり、日本SHLの公式サイトには載っていないので、必ず受検案内を読んでください。

## 前日まで

- [ ] 受検案内を最後まで読んだ（受検形式、締切、持ち物、電卓やメモ用紙の扱い）
- [ ] Web-CABなら、受検に使うパソコンと通信環境を決めた
- [ ] C-CABなら、会場と日時、本人確認に必要なものを確認した
- [ ] 紙のCABなら、会場の場所と集合時刻を確認した
- [ ] 各科目のページの「解き方の手順」を見直した
- [ ] よく眠れるように、新しい問題を解くのは早めに切り上げた

## 受検の1時間前

- [ ] Web-CABなら、通知を切り、ほかのアプリやタブを閉じた
- [ ] 静かで、途中で人に声をかけられない場所を確保した
- [ ] 受検案内で使ってよいとされているもの（筆記用具など）を手元に用意した
- [ ] 計算の工夫（25を掛ける、5を掛ける、よく出る分数と小数）を頭の中でひととおり確認した

## 最初の1分

- [ ] 画面や問題冊子の説明を最後まで読む。練習問題があれば必ず解く
- [ ] 命令表は、問題に入る前に記号と命令の対応をひととおり確認する
- [ ] 残り時間の表示がどこにあるかを確認する

## 受検中

- [ ] 1問で迷ったら、決めた秒数で選んで次へ進む（[時間配分](timing.md)を参照）
- [ ] 図形の科目は、部品を1つずつ追う
- [ ] 命令表と暗号は、変化を1つずつ実行する
- [ ] 性格検査は、仕事や学業の場面での普段の自分で答える

## 受検後

- [ ] 受検完了の画面やメールを確認する
- [ ] 手ごたえがなかった科目をメモしておく。次の受検までに、その科目のページで復習する

## 最後の練習として

受検の前日か前々日に、時間を計って通しで解いておくと、本番のペースがつかめます。[CAB形式の無料模擬テスト（PrepClubs）](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cab)は4科目で全179問・53分です。
