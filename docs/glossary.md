# 用語集

CABの対策でよく出てくる言葉を、五十音順とアルファベット順にまとめました。

| 用語 | 意味 |
|---|---|
| 暗号 | 図形が記号を通るとどう変わるかの例から記号の意味を推理し、新しい図形の変化を答える科目。[暗号](sections/angou.md) |
| 暗算 | 紙のCABで使われてきた計算科目の名前。式の答えを選ぶ形として知られる。[暗算（四則逆算）](sections/anzan.md) |
| 逆算 | 「□ ÷ 4 = 18」のように、答えから式の中の未知数を求めること |
| 誤謬率 | 解答した問題のうち間違えた割合。CABで評価に使われるかどうかは公開されていない |
| コンピテンシー | 仕事で成果を出す人に共通する行動の特徴。CABは「ヴァイタリティ」「チームワーク」など9つを予測する |
| 左右反転 | 縦の線を鏡にして、図形の左右を入れ替える変化。上下反転は横の線を鏡にする |
| 四則逆算 | 日本SHLの現在の製品ページでの計算科目の名前。等式中の未知数を求める |
| 受検案内 | 企業から届く、受検形式・締切・注意事項などの案内。細かいルールはここで確認する |
| 白黒反転 | 図形の黒い部分と白い部分をすべて入れ替える変化 |
| 性格検査（パーソナリティ） | 4つの記述から自分に最も近いものと最も遠いものを選ぶ検査。[性格検査（OPQ）](personality.md) |
| 玉手箱Ⅲ | 日本SHLの適性検査の1つ。計数（四則逆算）を含む |
| 日本エス・エイチ・エル（日本SHL） | CABを提供している会社 |
| ノルム | 結果を比べる基準になる受検者集団。CABは「大卒」 |
| 1つおきの規則 | 法則性で、1番目・3番目・5番目と、2番目・4番目に別々の規則がある並び |
| 法則性 | 並んだ図形の規則を見抜き、空欄に入る図形を選ぶ科目。[法則性](sections/housokusei.md) |
| 命令表 | 記号ごとに決まった命令を図形に順番どおり実行し、結果を答える科目。[命令表](sections/meireihyou.md) |
| C-CAB | テストセンターで受けるCAB |
| GAB | 日本SHLの総合職向け適性検査。言語と計数を測る |
| OPQ | 日本SHLのパーソナリティ検査。CAB、GAB、玉手箱Ⅲ、RABに共通して付いている |
| RAB | 日本SHLの適性検査の1つ。水平思考力を測る |
| Web-CAB（WebCAB） | パソコンで受けるCAB |
