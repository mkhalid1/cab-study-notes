# 時間配分

**ひとことで言うと：** CABは科目ごとに制限時間が区切られているとされ、どの科目も全問を丁寧に解く時間はありません。1問あたりの目安を体で覚え、迷った問題を切り捨てる判断を早くすることが得点につながります。

## 1問あたりの目安

科目ごとの問題数と時間は日本SHLの公式サイトには載っていません。下の目安は、[Web-CAB・紙のCAB・C-CABの違い](formats.md)で紹介した非公式の資料（2020年）の紙のCAB・WebCAB・C-CABの数字から計算したものです。

| 科目 | 1問あたり | 練習での目標 |
|---|---|---|
| 暗算（四則逆算） | 約11〜12秒 | 10秒以内 |
| 法則性 | 約18〜24秒 | 18秒以内 |
| 命令表 | 約22〜25秒 | 20秒以内 |
| 暗号 | 約28〜32秒 | 25秒以内 |

練習での目標を本番の目安より少し短くしているのは、本番では緊張で手が遅くなるからです。

## 科目ごとのペースの作り方

**暗算（四則逆算）：** 最初の見積もりで選択肢を2つ以下に絞れたら、そこで決めます。細かい計算に入る前に、桁と大きさで判断する習慣が時間を生みます。

**法則性：** 規則が10秒で見えなければ、1つおきの並びを疑います。それでも20秒で見えなければ、最も可能性の高い選択肢を選んで次へ進みます。

**命令表：** 最初の数問は命令表を見返すので遅くて構いません。命令を覚えるにつれて後半で取り返せます。ただし、1問の中で同じ命令を何度も見返しているなら、命令表を覚え直すサインです。

**暗号：** 記号の意味を確定させる段階に時間がかかります。記号1つの例から読み、1つの記号に20秒以上かかったら、残りの記号から先に解いてみます。

## 迷ったときの判断ルール

1. **2択まで絞れたら選ぶ。** 残りの時間を考えると、2択で悩み続けるより選んで進むほうが得です。
2. **手がかりがゼロなら、すぐ選んで次へ。** 同じ問題に戻れるかどうかは受検形式によって違い、公式には公開されていません。戻れない前提で判断します。
3. **終盤に慌てない。** 残り時間が少なくなっても、見積もりと消去法は使えます。最後まで1問ずつ解きます。

## 時間を計る練習のしかた

- **最初は時間を気にせず、型を覚える。** 各科目のページの「解き方の手順」どおりに、正確に解けるようにします。
- **次に1問ずつ時間を計る。** 目標の秒数に収まらない問題の型を書き出し、手順のどこで時間を使っているかを確認します。
- **最後に通しで解く。** 科目ごとの時間を区切って、通しで解く練習をします。[CAB形式の無料模擬テスト（PrepClubs）](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cab)は4科目で全179問・53分なので、本番に近い感覚でペースを確かめられます。
