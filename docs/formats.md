# Web-CAB・紙のCAB・C-CABの違い

**ひとことで言うと：** CABには、紙のマークシートで受ける形、自宅などのパソコンで受けるWeb版、テストセンターで受ける形の3つがあります。測る中身は同じ4科目と性格検査ですが、科目ごとの問題数と時間の配分が違うとされています。

## 3つの受検形式

日本SHLの[CABの製品ページ](https://www.shl.co.jp/service/assessment/cab/)は、実施形態を「紙、Web、テストセンター方式」と書いています（2026年11月25日確認）。日本SHLの製品ページでは、それぞれ次の名前が使われています。

| 名前 | 受ける場所 | 公式ページの説明 |
|---|---|---|
| CAB | 企業の会場などで、紙の問題冊子とマークシート | 実施形態に「紙」として記載 |
| WebCAB（Web-CAB） | 自宅などのパソコン | オンラインで実施できる |
| C-CAB | テストセンター | 厳格な本人認証を行うテストセンター形式にも対応 |

どの形式で受けるかは企業が決めます。受検案内のメールや書類に書かれている名前で確認してください。

## 公式に公開されていること、いないこと

| 項目 | 公式の情報 |
|---|---|
| 科目 | 四則逆算、法則性、命令表、暗号、パーソナリティ（OPQ） |
| 所要時間合計 | 72〜95分 |
| 科目ごとの問題数 | 公式サイトには記載なし |
| 科目ごとの制限時間 | 公式サイトには記載なし |
| 電卓・メモの可否 | 公式サイトには記載なし。受検案内の指示に従う |
| 合格ライン | 公開されていない。企業ごとに判断する |

## 非公式の参考情報：科目ごとの問題数と時間

日本SHLの製品を扱う人材会社マイナビが2020年に公開した製品案内のPDF（[エス・エイチ・エル適性テストのご紹介](https://mynavi-agent.jp/resource/employer/product/pdf/shl_document.pdf)）には、科目ごとの問題数と時間が載っています。**日本SHLの公式サイトの情報ではなく、2020年時点の資料なので、現在の本番と違う可能性があります。** そのうえで、参考として紹介します。

| 科目 | 紙のCAB | WebCAB | C-CAB |
|---|---|---|---|
| 計算 | 暗算 50問・10分 | 四則逆算 50問・9分 | 四則逆算 50問・9分 |
| 法則性 | 40問・15分 | 30問・12分 | 30問・9分 |
| 命令表 | 50問・20分 | 36問・15分 | 36問・13分 |
| 暗号 | 39問・20分 | 30問・16分 | 30問・14分 |
| パーソナリティ（OPQ） | 68問・約30分 | 68問・約20分 | 68問・約20分 |

この表の時間を足すと、紙のCABは約95分、Web-CABは約72分になり、公式ページの「72〜95分」と一致します。就活サイトの多くも、ほぼ同じ数字を紹介しています。

この数字が今も正しいとすると、1問あたりの時間はおおよそ次のとおりです。

| 科目 | 紙のCAB | WebCAB |
|---|---|---|
| 計算 | 約12秒 | 約11秒 |
| 法則性 | 約23秒 | 約24秒 |
| 命令表 | 約24秒 | 約25秒 |
| 暗号 | 約31秒 | 約32秒 |

どの形式でも、計算は1問10秒前後、図形の3科目は1問20〜30秒前後という感覚を持っておけば、大きく外れることはありません。

## 科目名の違い：暗算と四則逆算

同じ参考資料では、紙のCABの計算科目が「暗算」、WebCABとC-CABでは「四則逆算」と書かれています。日本SHLの現在の製品ページの測定項目は「四則逆算」です。

- **暗算（紙）：** 「24 × 16」のように、式の答えを選ぶ形として知られています。
- **四則逆算（Web・テストセンター）：** 「□ × 4 = 36」のように、式の中の未知数を求める形です。日本SHLの説明も「様々な等式中の、未知数の数字を求める問題」となっています。

どちらが出ても対応できるよう、このガイドの[暗算（四則逆算）](sections/anzan.md)では両方の形を練習します。

## 受検形式ごとの注意点

- **Web-CAB：** 自宅で受けられるぶん、環境づくりは自分の責任です。通信が安定した場所で、通知を切り、締切に余裕を持って受けましょう。
- **紙のCAB：** マークシートの塗り間違いや、解答欄のずれに注意します。問題冊子の余白をメモに使えるかどうかは、当日の指示に従ってください。
- **C-CAB：** 受検案内に沿って会場と日時を決めます。厳格な本人認証が行われるので、案内に書かれた持ち物を前日までにそろえておきます。

細かいルール（電卓、メモ用紙、途中の中断など）は企業や受検形式によって違い、公式サイトには載っていません。必ず受検案内を読んでください。当日の準備は[受検当日のチェックリスト](test-day-checklist.md)にまとめています。
