# 出典

このガイドの検査に関する事実は、次の情報源で確認しました。すべて2026年11月25日に確認しています。

## 日本エス・エイチ・エルの公式ページ

- [CAB（日本エス・エイチ・エル株式会社）](https://www.shl.co.jp/service/assessment/cab/)：対象、測定項目（四則逆算・法則性・命令表・暗号・パーソナリティ）、所要時間合計72〜95分、ノルム（大卒）、実施形態（紙、Web、テストセンター方式）、各科目が測る能力、パーソナリティ検査の回答形式、予測する職務適性とコンピテンシー、結果の活用法。
- [SHLの適性検査（玉手箱Ⅲ・GAB・CAB・RAB）を徹底比較](https://www.shl.co.jp/column/perspective/220617ysato/)：玉手箱Ⅲ、WebGAB、WebCAB、WebRABの対象・科目・テストセンター対応の比較と、OPQが共通科目であること。
- [「CAB」のご案内（資料ダウンロード）](https://www.shl.co.jp/materials/cab/)：CABが新卒・中途を問わずデジタル人材のポテンシャルを測る検査であること。

## このガイド独自の内容

次のものは、このガイドの作成者による内容で、公式の情報ではありません。

- すべての練習問題と15分診断テストの問題（28問）。日本SHLの問題や他の対策本・サイトの問題ではなく、このガイドのために作ったオリジナルです。図形はすべてプログラムで生成し、正解も同じデータから計算して確かめています。
- 命令表の記号と命令の対応、暗号の記号の意味。本番の記号や命令とは異なります。
- 解き方の手順、時間配分の目標、対策スケジュール、練習での目標正答率。

## 提携関係について

このガイドは独立した学習資料で、日本エス・エイチ・エル株式会社、SHLグループ、およびCABを利用する企業とは関係がなく、承認や後援も受けていません。CAB、GAB、OPQ、玉手箱などの名称は、それぞれの権利者の商標です。
