# CABとはどんな適性検査か

**ひとことで言うと：** CABは日本エス・エイチ・エル（日本SHL）が提供する、ITエンジニアやデジタル人材の素質を測る適性検査です。プログラミングの知識は問われず、計算と図形のパズルで「新しい技術を身につけられる力」を見ます。

SE・プログラマー職の選考で出会うことが多く、SPIや玉手箱とは問題の雰囲気がまったく違います。初見だと命令表や暗号で手が止まりやすいので、形式を知っているかどうかで差がつく検査です。

## 公式に公開されている基本情報

日本SHLの[CABの製品ページ](https://www.shl.co.jp/service/assessment/cab/)に載っている情報は次のとおりです（2026年11月25日確認）。

| 項目 | 公式ページの記載 |
|---|---|
| 提供元 | 日本エス・エイチ・エル株式会社 |
| 対象 | ITエンジニアやデジタル人材のポテンシャル測定。新卒・中途を問わず、エンジニア未経験者にも使える |
| 測定項目 | 四則逆算、法則性、命令表、暗号、パーソナリティ（OPQ） |
| 所要時間合計 | 72〜95分 |
| ノルム（比較集団） | 大卒 |
| 実施形態 | 紙、Web、テストセンター方式 |
| 予測する職務適性 | SE、プログラマー、カスタマーエンジニア、プロジェクトマネージャー |
| そのほかの予測 | 「ヴァイタリティ」「チームワーク」など9つのコンピテンシーと、面接でのチェックポイント |

科目ごとの問題数と制限時間は、日本SHLの公式サイトには載っていません。参考になる数字は[Web-CAB・紙のCAB・C-CABの違い](formats.md)にまとめましたが、いずれも非公式の情報です。

## 4つの能力科目と性格検査

公式ページは、各科目が何を測るかを次のように説明しています。このガイドの言葉で要約すると：

| 科目 | 公式の説明の要点 | このガイドでの呼び方 |
|---|---|---|
| 四則逆算 | 等式の中の未知数を求め、おおよその答えを速く正確に出す力 | [暗算（四則逆算）](sections/anzan.md) |
| 法則性 | 流れを持った図形群に潜む法則性を速く正確に見分ける力。プログラマーとしての優秀性 | [法則性](sections/housokusei.md) |
| 命令表 | 与えられた指示・命令を速く正確に記憶し、使いこなす力。コンピュータ言語への適応 | [命令表](sections/meireihyou.md) |
| 暗号 | 表面の事象から背後の構造や関係を推理する力。システム設計やデバッグの適性 | [暗号](sections/angou.md) |
| パーソナリティ | 4つの記述から自分に最も近いものと最も遠いものを1つずつ選ぶ | [性格検査（OPQ）](personality.md) |

紙のCABでは計算の科目が「暗算」と呼ばれてきました。日本SHLの現在の製品ページでは「四則逆算」という名前です。就活サイトや問題集では両方の呼び方が混ざっているので、このガイドでは両方の形式を扱います。

## なぜIT企業がCABを使うのか

日本SHLは、CABが長年多くの企業で使われ、入社後の業績との関連（妥当性）が繰り返し確かめられていると説明しています。ポイントは「知識を問わない」ことです。情報系の学部でなくても、未経験からエンジニアを目指す人でも、同じ物差しで素質を見られます。

逆に言えば、プログラミング経験があっても高得点が保証されるわけではありません。命令表は「命令を正確に順番どおり実行できるか」、暗号は「入力と出力から処理を推理できるか」を見ます。どちらもコードを書くときの頭の使い方に近いのですが、問題は図形で出るので、形式への慣れがそのまま点数に出ます。

## よく似た検査との違い

日本SHLのコラム「[SHLの適性検査（玉手箱Ⅲ・GAB・CAB・RAB）を徹底比較](https://www.shl.co.jp/column/perspective/220617ysato/)」によると：

| 検査 | 主な対象 | 知的能力科目 | テストセンター |
|---|---|---|---|
| 玉手箱Ⅲ | 新卒・中途（総合職） | 言語（大意把握）、計数（四則逆算）、英語 | なし |
| WebGAB | 新卒・中途（総合職） | 言語（論理）、計数（図表理解） | あり |
| WebCAB | IT・技術職、デジタル人材職 | 四則逆算、法則性、命令表、暗号 | あり |
| WebRAB | 新卒・中途（総合職、イノベーティブな職種） | 言語（論理）、計数（推論） | なし |

玉手箱の「四則逆算」とCABの「四則逆算」は同じ名前の科目です。玉手箱の対策をしたことがある人は、計算の科目だけは経験が生きます。図形の3科目（法則性・命令表・暗号）はCAB独自のものです。

## 全科目に共通する考え方

4科目とも、1問にかけられる時間は短めです。共通して効くのは次の3つです。

1. **ルールを言葉にする。** 「黒い丸が時計回りに1つずつ進む」のように、見つけた規則を頭の中で短い文にします。言葉にできない規則は、選択肢で迷います。
2. **1つずつ変化を追う。** 命令表と暗号では、2つの変化を同時に追おうとするのが一番のミスのもとです。1回の変化ごとに図形を確定させます。
3. **止まったら次へ。** 1問で30秒以上迷ったら、いったん選んで先に進みます。詳しくは[時間配分](timing.md)を見てください。

## 本番に近い形で練習する

形式に慣れるには、時間を計って通しで解くのが一番です。PrepClubsの[CAB形式の無料模擬テスト](https://prepclubs.com/ja/cab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=cab)は、暗算・法則性・命令表・暗号の4科目を通しで解けます。まずはこのリポジトリの[15分診断テスト](diagnostic.md)で、どの科目から手をつけるか決めましょう。
